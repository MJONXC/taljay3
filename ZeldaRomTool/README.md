🌿 About the project

ZeldaRomTool is an Android tool created to make it easier to extract, organize and manage the internal files of games.

The project was inspired by the legendary The Legend of Zelda franchise, especially its visual identity, its universe and the passion for exploring every detail of the games.

However, ZeldaRomTool was not built exclusively for Zelda games.

Its purpose is much broader: to offer a tool that can work with different games and compatible file formats, giving players, enthusiasts and developers more control over the contents of their own ROMs.

Zelda was the inspiration. Exploring games is the mission.

⚔️ Main features

📦 ROM extraction

- Reading the file structures of compatible games.
- Extracting internal contents.
- Organizing extracted files into directories.
- Support for reading PFS0 and HFS0 structures.
- Processing compatible NSP and XCI files.

🗂️ File management

- Organizing extracted files.
- Separating contents into their respective folders.
- Managing extraction directories.
- Access to the games' internal files.

🔍 Content analysis

- Reading the internal structure of ROMs.
- Identifying the files present in packages.
- Viewing information about the files found.
- Processing compatible game structures.

🛠️ System and settings

- Native Android interface.
- Settings built into the app.
- Structure ready to receive new features.
- Planned version check and update system.

🔄 Updates

The project also plans an update system built into the app, using the versions published on GitHub as the reference for checking for new versions.

🎮 It's not just about Zelda!

Despite carrying Zelda in its name, ZeldaRomTool aims to go beyond a single franchise.

The goal is to offer compatibility with different games, as long as their structures and formats are supported by the extraction system.

Among the franchises that represent the gaming universe that inspired and motivated the project are:

- The Legend of Zelda
- Super Mario
- Pokémon
- Metroid
- Animal Crossing
- Fire Emblem
- Xenoblade Chronicles
- Other compatible franchises and games.

Important: compatibility depends on the formats, structures and file systems implemented. A franchise appearing on this list does not mean full support for all of its games.
